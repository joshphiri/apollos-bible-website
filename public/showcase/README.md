# Apollos showcase assets

Owner-approved Home-first website tour.
Order: Home → Voice Bible → Sermons → Verse cards.

The four screenshots are real, unretouched app captures. Voice Bible uses the approved
replacement App Store library screenshot. Sermons shows an approved saved-sermon
detail screen with main points and Scripture references, not the library layout.
Input hashes are pinned in scripts/website-showcase.test.cjs.

Phone model: Iphone 16 Pro by tranminhluan, CC BY 4.0.
Source: https://sketchfab.com/3d-models/iphone-16-pro-96be8c7e49fa4f949855db3e7f2e64e0
Licence: https://creativecommons.org/licenses/by/4.0/
Adaptation: front screen material and UVs changed to display real Apollos screenshots;
body geometry retained. Visible attribution is in the website footer.

Viewer: Google model-viewer 4.3.1, self-hosted, Apache 2.0 (vendor/LICENSE).
The minified runtime is an intentional static vendor asset, not application build output.
No new npm dependencies, third-party model hosting or telemetry.

Physical iPhone Safari and slower-network checks remain separate device checks.
The website does not claim public App Store availability before launch.
